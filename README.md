# TypeTrack ⌨️

> *"Practice calmly. Build confidence. Get faster over time."*

**TypeTrack** is a modern, beginner-friendly web-based typing coach designed to help individuals build touch typing muscle memory, improve accuracy, and develop effortless speed through guided practice, gentle gamification, and a serene, distraction-free environment.

---

## ✨ Key Features

- **Beginner-Friendly Typing Coach**: Non-judgmental, encouraging guidance that focuses on consistent progress and muscle memory rather than stressful failure states.
- **8-Level Progressive Curriculum**:
  - **Level 1**: Keyboard Basics (Home Row Anchors: `A S D F` & `J K L ;`)
  - **Level 2**: Home Row Expansion (`E`, `I`, `G`, `H`, `R`, `U`)
  - **Level 3**: Common Digraphs & Letter Pairs (`TH`, `HE`, `ING`, `ER`)
  - **Level 4**: Everyday Words (High-frequency vocabulary)
  - **Level 5**: Sentences & Flow (Punctuation, capitalization, cadence)
  - **Level 6**: Accuracy Focus (Deliberate precision)
  - **Level 7**: Speed & Rhythm (Confidence sprints)
  - **Level 8**: Advanced Practice (Numbers, symbols, literary passages)
- **Interactive Visual Keyboard Guide**: Shows home-row tactile bumps, finger assignment zones (color-coded per finger), and real-time guidance showing which exact finger to use for the next character.
- **Peaceful Focus Mode**: Enter a quiet digital workspace with zero distractions, enlarged typography, and minimalist live indicators.
- **Synthesized Web Audio Feedback**: Zero-latency, relaxing mechanical switch clicks, mellow wooden clicks, or soft bubble sounds built with the Web Audio API.
- **Comprehensive Progress Dashboard**:
  - Answers the 4 key questions: *How am I doing?*, *What did I practice?*, *Am I improving?*, and *What should I practice next?*
  - Interactive SVG progression charts for WPM and accuracy trends.
  - Daily practice streaks and 12 collectible milestone badges.
- **Personalized Post-Session Coach Insights**: Encouraging tips and personalized next-step suggestions based on your speed, accuracy, and flow.
- **Theme & Typography Customization**: Dark, Light, and Warm Sepia themes with comfortable, responsive typography.

---

## 🛠️ Tech Stack

- **Framework**: React 19 + TypeScript
- **Bundler**: Vite
- **Styling**: Tailwind CSS v4
- **Audio**: Web Audio API (Synthesizer)
- **Icons**: Lucide React
- **Animations**: Motion & CSS keyframe carets

---

## 🚀 Getting Started

1. **Install dependencies**:
   ```bash
   npm install
   ```

2. **Start the development server**:
   ```bash
   npm run dev
   ```

3. **Build for production**:
   ```bash
   npm run build
   ```
